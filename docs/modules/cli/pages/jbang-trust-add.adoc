= JBANG TRUST ADD

== NAME

jbang trust add -- Add trust domains.

== SYNOPSIS

[source]
----
jbang trust add [OPTIONS] <rules>...
----

Trusts scripts whose URL starts with one of the given prefixes. Keep the prefix
as narrow as you can, e.g. a user or repository instead of a whole site.

Examples:

[source,bash]
----
jbang trust add https://github.com/jbangdev/
jbang trust add https://github.com/myorg/scripts/
----


== OPTIONS

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== ARGUMENTS

*<rules>*::
Rules for trusted sources
