= JBANG DEPS SEARCH

== NAME

jbang deps search -- Search for artifacts in local and central Maven repositories.

== SYNOPSIS

[source]
----
jbang deps search [OPTIONS] [<args>]
----

Interactively searches your local and the central Maven repository. The chosen
artifact is added to the target file if you give one, otherwise its coordinates
are printed.

Examples:

[source,bash]
----
jbang deps search jackson
jbang deps search jackson app.java
jbang deps search --query=jackson --target=build.jbang
----


== OPTIONS

*--max*=<max>::
Maximum number of results to return.
+
Default: `100`

*-q*, *--query*=<query>::
Artifact pattern to search for.

*--target*=<target>::
Target where to add the dependency, i.e. app.java or build.jbang

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== ARGUMENTS

*<args>*::
[query] [target]
