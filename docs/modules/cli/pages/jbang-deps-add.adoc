= JBANG DEPS ADD

== NAME

jbang deps add -- Add dependencies to a jbang file.

== SYNOPSIS

[source]
----
jbang deps add [OPTIONS] <deps target>...
----

Adds one or more groupId:artifactId:version dependencies to the target file,
which comes last.

Examples:

[source,bash]
----
jbang deps add info.picocli:picocli:4.7.6 app.java
jbang deps add org.slf4j:slf4j-api:2.0.13 org.slf4j:slf4j-simple:2.0.13 build.jbang
----


== OPTIONS

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== ARGUMENTS

*<deps target>*::
Dependencies to add (groupId:artifactId:version) and target file (.java or build.jbang)
