= JBANG JDK INSTALL

== NAME

jbang jdk install -- Installs a JDK.

== SYNOPSIS

[source]
----
jbang jdk install [OPTIONS] <versionOrId> [<pathOrUrl>]
----

Installs a JDK by major version or id. Pass a path (or an installable archive)
as well to register a JDK you already have instead of downloading one. If a
matching JDK is already installed it is left as-is; use --force to replace it.

Examples:

[source,bash]
----
jbang jdk install 21
jbang jdk install 21 /opt/java/jdk-21
jbang jdk install --force 21
----


== OPTIONS

*--jdk-providers*=<jdk-providers>::
Use the given providers to manage JDKs

*--jdk-distros*=<jdk-distros>::
Use the given distributions to install new JDKs

*-f*, *--force*::
Force installation even when already installed

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== ARGUMENTS

*<versionOrId>*::
The version or id to install

*<pathOrUrl>*::
Pre installed JDK path or URL/path to installable archive
