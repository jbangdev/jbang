= JBANG APP

== NAME

jbang app -- Manage scripts installed on the user's PATH as commands.

== SYNOPSIS

[source]
----
jbang app [OPTIONS] [COMMAND]
----

Installs scripts, jars, GAVs or aliases as commands on your PATH, so you can run
them without typing jbang. Run `jbang app setup` once to put the install folder
on your PATH.

Examples:

[source,bash]
----
jbang app install --name hello hello.java
jbang app list
jbang app uninstall hello
jbang app setup
----


== OPTIONS

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== COMMANDS

* xref:jbang:cli:jbang-app-install.adoc[*install*] - Install a script as a command.
* xref:jbang:cli:jbang-app-list.adoc[*list*] - Lists installed commands.
* xref:jbang:cli:jbang-app-uninstall.adoc[*uninstall*] - Removes a previously installed command.
* xref:jbang:cli:jbang-app-setup.adoc[*setup*] - Make jbang commands available for the user.
