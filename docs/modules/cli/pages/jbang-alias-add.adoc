= JBANG ALIAS ADD

== NAME

jbang alias add -- Add alias for script reference.

== SYNOPSIS

[source]
----
jbang alias add [OPTIONS] [<scriptOrFile>] [<params>...]
----

Saves a script, jar or GAV under a name, together with any options and arguments
you give (dependencies, runtime options, ...), so `jbang <name>` reproduces it.

Examples:

[source,bash]
----
jbang alias add --name hello hello.java
jbang alias add --name cowsay --deps org.slf4j:slf4j-simple:2.0.9 cowsay.java
jbang alias add --name greet hello.java World
jbang alias add --global --name tool org.example:tool:1.0 serve
----


== OPTIONS

*-s*, *--sources*=<sources>::
Add additional sources.

*--files*=<files>::
Add additional files.

*-T*, *--source-type*=<source-type>::
Force input to be interpreted as the given type. One of: java, jshell, kotlin, groovy, markdown.

*--jsh*::
Force input to be interpreted with jsh/jshell. Deprecated: use '--source-type jshell'

*--catalog*=<catalog>::
Path to catalog file to be used instead of the default

*--jdk-providers*=<jdk-providers>::
Use the given providers to manage JDKs

*--jdk-distros*=<jdk-distros>::
Use the given distributions to install new JDKs

*-j*, *--java*=<java>::
JDK version to use for running the script.

*-m*, *--main*=<main>::
Main class to use when running. Used primarily for running jar's. Can be a glob pattern using ? and *.

*--module*=<module>::
Treat resource as a module. Optionally with the given module name

*-C*, *--compile-option*=<compile-option>::
Options to pass to the compiler

*--manifest*=<key>=<value>::
Add entry to the JAR manifest (e.g. --manifest=Main-Class=com.example.Main)

*--[no-]integrations*::
Enable or disable integration execution (default: true)

*-D*=<key>=<value>::
set a system property
+
Default: `true`

*--deps*=<deps>::
Add additional dependencies (Use commas to separate them).

*--repos*=<repos>::
Add additional repositories.

*--cp*=<cp>::
Add class path entries.
+
Aliases: `--class-path`

*--ignore-transitive-repositories*::
Ignore remote repositories found in transitive dependencies
+
Aliases: `--itr`

*-n*, *--native*::
Build using native-image

*-N*, *--native-option*=<native-option>::
Options to pass to the native image tool

*-R*, *--runtime-option*=<runtime-option>::
Options to pass to the Java runtime
+
Aliases: `--java-options`

*--jfr*=<jfr>::
Launch with Java Flight Recorder enabled.

*-d*, *--debug*=<debug>::
Launch with java debug enabled. Set host/port or provide key/value list of JPDA options (default: )

*--enableassertions*::
Enable assertions
+
Aliases: `--ea`

*--enablesystemassertions*::
Enable system assertions
+
Aliases: `--esa`

*--javaagent*=<key>=<value>::
Java agent to use
+
Default: ``

*--[no-]cds*::
If specified Class Data Sharing (CDS) will be used for building and running (requires Java 13+)

*-i*, *--interactive*::
Activate interactive mode

*-g*, *--global*::
Use the global (user) catalog file

*-f*, *--file*=<file>::
Path to the catalog file to use

*--description*=<description>::
A description for the alias

*--name*=<name>::
A name for the alias

*--force*::
Force overwriting of existing alias

*--enable-preview*::
Activate Java preview features

*--docs*=<docs>::
Documentation reference for the alias

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== ARGUMENTS

*<scriptOrFile>*::
A file or URL to a Java code file

*<params>*::
Parameters to pass on to the script
