= JBANG JDK JAVA-ENV

== NAME

jbang jdk java-env -- Prints out the environment variables needed to use the given JDK.

== SYNOPSIS

[source]
----
jbang jdk java-env [OPTIONS] [<versionOrId>]
----

Prints the shell commands that put a jbang-managed JDK on PATH and set
JAVA_HOME. Evaluate the output to use that JDK in your current shell.

Examples:

[source,bash]
----
eval $(jbang jdk java-env 21)
jbang jdk java-env 21
----


== OPTIONS

*--jdk-providers*=<jdk-providers>::
Use the given providers to manage JDKs

*--jdk-distros*=<jdk-distros>::
Use the given distributions to install new JDKs

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== ARGUMENTS

*<versionOrId>*::
The version of the JDK to select
