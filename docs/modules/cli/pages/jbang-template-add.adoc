= JBANG TEMPLATE ADD

== NAME

jbang template add -- Add template for script reference.

== SYNOPSIS

[source]
----
jbang template add [OPTIONS] <files>...
----

Saves one or more files as a named template. The first file becomes the script;
the rest are copied alongside it. Use --property for values `jbang init` asks
for.

Examples:

[source,bash]
----
jbang template add --name logo showlogo.java img.jpg
jbang template add --global --name tool tool.java
jbang template add --name greet -P greeting=Greeting::Hello greet.java
----


== OPTIONS

*-d*, *--description*=<description>::
A description for the template

*--name*=<name>::
A name for the template

*--force*::
Force overwriting of existing template

*-P*, *--property*=<property>::
Template property (key=description::defaultValue)

*-g*, *--global*::
Use the global (user) catalog file

*-f*, *--file*=<file>::
Path to the catalog file to use

*-h*, *--help*::
Display this help and exit

*--config*=<config>::
Path to config file to be used instead of the default

*--insecure*::
Enable insecure trust of all SSL certificates.

*--[no-]verbose*::
jbang will be verbose on what it does.

*--[no-]quiet*::
jbang will be quiet, only print when error occurs.

*-o*, *--[no-]offline*::
Work offline. Fail-fast if dependencies are missing.

*--[no-]fresh*::
Make sure we use fresh (i.e. non-cached) resources.

*-x*, *--[no-]stacktrace*::
Print exceptions stacktraces to stderr (even when quiet).

*--netrc*=<netrc>::
Path to a .netrc file for HTTP authentication credentials.

*--no-netrc*::
Disable .netrc authentication lookup.

== ARGUMENTS

*<files>*::
Paths or URLs to template files
